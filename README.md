# Geochemistry Data Plotter

**Geochemistry Data Plotter** is a standalone Windows desktop application for geochemical data visualization, petrological classification, exploratory data analysis, and publication-quality graphical output. Excel is a powerful data manipulation software but it is absolutely terrible for plotting data. I used a great program called IgPet (now owned by Rockware) when I was a graduate student for plotting my mineral chemistry data. I took a lot of inspiration from IgPet and created this program to accomplish a similar task - make nice data plots without having to slog through Excel's horrible UI. 

The application operates offline and provides an interactive interface for working directly with Excel-based geochemical and mineralogical datasets.
